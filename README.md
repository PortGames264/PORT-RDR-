Sobre o projeto

O PORT RDR é um projeto de adaptação para Android, com o objetivo de executar Red Dead Revolver, originalmente lançado para Xbox, em dispositivos Android compatíveis.

O projeto busca oferecer uma experiência adaptada para dispositivos móveis, com controles na tela, suporte a controles físicos e interface otimizada para orientação horizontal.

✨ Recursos

- Compatibilidade com arquitetura ARM64.
- Interface adaptada para Android.
- Orientação horizontal.
- Controles virtuais na tela.
- Suporte a gamepads físicos.
- Configuração e associação de controles.
- Opções de personalização dos controles virtuais.
- Melhorias de compatibilidade com dispositivos Android.

📱 Plataforma

- Android
- ARM64 (arm64-v8a)

🛠️ Ambiente de desenvolvimento

- Android SDK
- Android NDK
- Kotlin
- Gradle
- Termux

📦 Compilação

O projeto utiliza Gradle para gerar o APK de depuração.

Dentro da pasta "android", execute:

./gradlew assembleDebug

O APK será gerado em:

app/build/outputs/apk/debug/app-debug.apk

🚧 Estado do projeto
